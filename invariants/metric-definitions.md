# Metric Definitions

This file lists the named metric symbols used by the Pi³XI Canonical Spec.

| Symbol | Phase            | Definition                                    |
|--------|------------------|-----------------------------------------------|
| `d_KG` | Phase 1          | To be specified in a later spec release.      |
| `d_GF` | Phase 1          | To be specified in a later spec release.      |
| `d_KF` | Phase 1          | To be specified in a later spec release.      |
| `d_W`  | Future expansion | To be specified in a later spec release.      |
| `d_M`  | Future expansion | To be specified in a later spec release.      |

The Phase 1 invariant vector is `I = (d_KG, d_GF, d_KF)`. See [`phase1-invariants.md`](phase1-invariants.md).
